# royals-intelligence
Rajasthan Royals IPL 2027 – Data-Driven Auction Intelligence &amp; Player Performance Analytics Dashboard


Royals Intelligence – IPL 2027

This project is an interactive cricket analytics dashboard developed to study player performance and support Rajasthan Royals' IPL 2027 auction strategy.

The main focus is to understand how players perform in pressure situations and identify potential players based on their past performance.

Project Overview

The dashboard includes:

- Batting performance analysis
- Bowling performance analysis
- Player rankings in pressure situations
- Player-wise performance details
- Search and filter options
- Auction strategy insights

Tools & Technologies

- Python – Data cleaning, processing and analysis
- Pandas & NumPy – Data handling and calculations
- HTML – Dashboard structure
- CSS – Design and styling
- JavaScript – Interactive features and data visualization

Analysis Approach

Historical cricket match and ball-by-ball data has been used to study player performance. Specific pressure situations were identified using match conditions, innings progress and required run rate.

Players were evaluated using selected batting and bowling performance indicators to prepare comparative rankings.

Project Objective

The objective is to use cricket data to support better player evaluation and make the auction selection process more data-driven.

Note

The rankings and insights are based on the available dataset and the project's analytical methodology. They are intended for analysis and shortlisting purposes.
